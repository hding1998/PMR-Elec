【文件名】DL/T 722-2014 变压器油中溶解气体分析和判断导则
【类别】fault_case
【内容】

1. 变压器油中溶解气体分析原理
当变压器内部因电应力或热应力发生故障时，绝缘油和固体绝缘材料（如纤维素）会分解产生特定气体。这些气体溶解于油中，其种类和浓度与故障类型和严重程度直接相关。

热故障：温度升高导致油和固体绝缘热分解，主要产生甲烷（CH4）、乙烯（C2H4）、乙烷（C2H6）等烃类气体，严重过热可能生成少量乙炔（C2H2）。

电故障：放电（如局部放电、电弧）引发油分子裂解，生成氢气（H2）、乙炔（C2H2）等高能气体。

受潮或氧化：水分和氧气加速油的老化，产生氢气（H2）和一氧化碳（CO）等。

2. 三比值法
三比值法是在热动力学和实践的基础上总结得出的，利用五种气体（CH4、C2H4、C2H6、C2H2、H2）的三对比值进行故障类型判断的方法。

三对比值：
- C2H2/C2H4
- CH4/H2
- C2H4/C2H6

编码规则：
| 气体比值范围 | C2H2/C2H4 | CH4/H2 | C2H4/C2H6 |
| <0.1 | 0 | 1 | 0 |
| [0.1, 1) | 1 | 0 | 0 |
| [1, 3) | 1 | 2 | 1 |
| ≥3 | 2 | 2 | 2 |

典型编码组合与故障类型：
| 编码 | 故障类型判断 |
| 0,0,0 | 正常老化 |
| 0,1,0 | 局部放电 |
| 1,0,0 | 低能量放电 |
| 1,2,1 | 低能放电兼过热 |
| 2,0,2 | 高温过热（>700°C） |
| 2,2,2 | 高能量放电 |
| 0,2,0 | 低温过热（<150°C） |
| 0,2,1 | 中温过热（150~300°C） |
| 0,2,2 | 中高温过热（300~700°C） |

3. 气体比值的图示法
利用气体的三对比值在坐标图上建立的图示法，可直观地区分不同类型故障。包括三比值法三维图和杜瓦尔三角形法。

4. CO2/CO比值的辅助判断
当故障涉及固体绝缘材料时，一般CO2/CO小于3，最好用CO2和CO的增量进行计算。
当固体绝缘材料老化时，一般CO2/CO大于7。

5. 其他诊断方法
5.1 特征气体法：根据故障类型对应的主要特征气体进行判断。
- H2为主：局部放电或受潮
- C2H2为主：电弧放电
- CH4、C2H4为主：过热故障
- CO、CO2增长：固体绝缘老化或过热涉及固体绝缘

5.2 杜瓦尔三角形法：仅使用CH4、C2H4和C2H2三种气体，将气体转换为三角坐标并绘制三角形，可识别局部放电、电故障和热故障。

5.3 产气速率判断：
- 总烃绝对产气速率：大于6mL/d（开放式）和12mL/d（密封式）认为设备有异常
- 相对产气速率：大于10%/月认为设备有异常

6. 注意值与跟踪分析
当特征气体含量超过注意值或产气速率异常时，应缩短试验周期进行跟踪分析，必要时结合电气试验进行综合判断。

7. 故障严重程度判断
7.1 轻微故障：特征气体含量略超注意值，产气速率低，设备可继续运行并加强监测。
7.2 一般故障：特征气体含量明显超标，产气速率较快，建议安排计划检修。
7.3 严重故障：特征气体含量大幅超标，产气速率快，建议尽快停运检查。
7.4 危急故障：C2H2含量急剧升高或H2含量异常高，伴有气体继电器动作，应立即停运。
